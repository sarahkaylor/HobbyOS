# NOTE: written against integ9; C1-k6's 9d47b051 now bounds every task halt (safe_wfi) to 1 ms, which turns every T row
# below into 'woken within 1 ms' for task context.  The idle loop is left to the IPIs that hand it work.
# x86_64 halt ("sti; hlt" = safe_wfi) wait sites at cp-fat, and what ends each halt.
# Context: an AP has NO periodic interrupt of its own (timer.c: AP LVT not armed;
# C1-k6's 0x84 one-shot fires only for a covered park deadline).  The only
# periodic wake is CPU 0's PIT tick, which broadcasts 0x81.  CPU 0 stops
# broadcasting whenever it runs with IF=0 -- in particular while it spins in
# ylock_acquire inside a syscall (SFMASK 0x47700 masks IF at entry).  A halt
# whose only waker is "some interrupt" is therefore unbounded while CPU 0 spins
# on a lock the halted CPU holds (or on anything that waits for it).
#
# waker: R = a real, directed waker exists; T = relies on the broadcast tick
# (or another incidental interrupt); D = bounded by a deadline, but the
# deadline is only checked after a wake, so it is NOT a bound without one.
#
# site                                   function                         waker  holds a lock others spin on?

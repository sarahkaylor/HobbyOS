# ROOT CAUSE (reading src/kernel/arch/x64/trap.c watchdog_tick): `now = timer_get_ms()` is read at the top of the tick; the
# tick then prints [NFSIO] every 30 s through wd_puts -> uart_putc_dbg -> cons_kputc -> kconsole -> cons_hw_tx, which sets
# uart_last_activity_ms = timer_get_ms() -- a LATER ms than `now` once the print crosses a millisecond (or another CPU prints
# in between).  `if (now - uart_last_activity_ms < WATCHDOG_SILENCE_MS)` is uint64_t arithmetic: now < last underflows to
# ~2^64, the test fails, and the watchdog reports 20 s of silence plus a CPU dump.

## reading (C6-venus)
- v15/v16 VKD3D_FRAME_RATE=10/30 on the fixed fence-wake kernel: the limiter is set but has no effect (40-67 fps), and the fault recurs.
- v17/v18 (p8caps timing rows, Venus and lavapipe): Sleep / SleepEx / event / waitable-timer waits are NOT short (50 ms waits take 50-60 ms),
  but every QueryPerformanceCounter interval is a whole number of milliseconds: CLOCK_MONOTONIC (sys_gettime) was
  timer_get_ms(), so the game's QPC (Wine: clock_gettime(CLOCK_MONOTONIC)) had 1 ms resolution, against ns on Linux (P0).
- v19..v22: the monotonic clocks (1, 4, 6, 7) answer from timer_get_us() (the same TSC, microsecond resolution); QPC
  intervals become 49.94 / 499.9 ms.  Result: v20, v21, v22 reach the MAIN MENU (launch -> menu ~156 s including
  the harness's PRESS SPACE presses); v19 shows no fault in 25 min but sat on the title/loading screen (stopped by PID).
  Before the change: 1 main menu (v7) in 13 Venus boots, every other boot died at stop 11.
